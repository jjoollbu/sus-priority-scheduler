# Projeto A3 — Simulador de Filas de Prioridade

Simulador acadêmico de filas de prioridade baseado em um
cenário de triagem hospitalar inspirado no SUS/Manchester.

## Tecnologias

- Python
- Programação Orientada a Objetos
- Streamlit
- SQLite
- Git e GitHub

## Objetivo

Simular o atendimento de pacientes com diferentes níveis
de prioridade, aplicando mecanismos de fairness para
mitigar starvation e monitorando indicadores de SLA.
